# GDGoC Kickoff Website

A simple HTML5 website showcasing the GDGoC Kickoff Event at COMSATS University Islamabad, Attock Campus.

## Features

* Navigation links to different sections of the website
* Hero section introducing the kickoff event
* About GDGoC section
* Event highlights
* Photo gallery
* Seven GDGoC teams
* Join form with team selection
* Contact section and footer

## Technologies Used

* HTML5
* Semantic HTML elements

## Project Structure

```text
gdgoc-kickoff-website/

    ├── group-photo.jpeg

```

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
