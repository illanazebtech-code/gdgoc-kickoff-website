# GDGOC Kickoff Event Website

A single-page website for the **GDG on Campus kickoff event at COMSATS Attock Campus**,
built for the GDGOC Web Team Challenge with plain HTML5, CSS and a little JavaScript.

## Project structure

```
gdgoc-kickoff-website/
├── README.md
├── index.html
└── assets/
    ├── group-photo.jpeg      <- group photograph (gallery section)
    ├── kickoff-banner.jpeg   <- stage/crowd photo (hero banner)
    ├── gdgoc-logo.png        <- square crop of the chapter logo (nav, footer, favicon)
    ├── gdgoc-logo-full.png   <- full logo with wordmark (About section)
    ├── style.css
    └── main.js
```

## Run it

Just open `index.html` in a browser, or in VS Code right-click it and choose
**Open with Live Server** (needs the Live Server extension).

## Before you submit - checklist

- [ ] Confirm the photos in `assets/` are the official ones provided with the challenge.
- [ ] Update the alt text of each image if you want it more specific.
- [ ] Replace the `#` social links in the footer with the official GDGOC handles.
- [ ] Check the Highlights section against confirmed event details (look for the `TODO` comments).

## What's inside

Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `figure`, `form`, `footer`),
a proper heading hierarchy, labelled form inputs with suitable types and `required`,
meaningful `alt` text, internal anchor navigation, external Google Developer links,
and a "Back to Top" link.

The registration form is a **demo only**: it validates in the browser but doesn't store
or send anything.

## Submitting

1. Fork the challenge repo and clone your fork.
2. Copy these files in, commit, and push.
3. Submit your public repository link.
